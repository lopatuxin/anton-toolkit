# Общий маркетплейс Claude и Codex

Источник всех семи плагинов — `https://github.com/lopatuxin/anton-toolkit`, ветка `main`. Личные правила и память остаются в Obsidian.

## Что редактировать

- `plugins/` — общие навыки, агенты, справочники, скрипты и исходная версия для Claude.
- `adapters/codex/` — особенности Codex, включая распределение моделей и хуки.
- `codex/plugins/` и `.agents/plugins/marketplace.json` — автоматически собранная версия для Codex. Вручную её не правят.

Claude использует `.claude-plugin/marketplace.json`, Codex — `.agents/plugins/marketplace.json`. Оба каталога находятся в одном Git-репозитории. При изменении исходника сборка меняет версию соответствующего пакета Codex по содержимому, даже если версия Claude не менялась.

## Модели

Настройки Claude остаются в `plugins/*/agents/*.md`. Для Codex отдельный файл `adapters/codex/models.json`: разработчики и devops — GPT-6.1 Sol/high; QA и test-writer — Sol/medium; code-reviewer — GPT-6 Astra/medium; mr-spec-reviewer — Astra/xhigh. Остальные роли наследуют модель основного чата, пока владелец не назначит другую.

В Codex для `task-build` выберите GPT-6 Astra под полем ввода. Оркестратор и планировщик работают в этом чате с выбранным уровнем рассуждения. `task-build` проверяет модель при запуске и при продолжении после ответа пользователя.

## Получить изменения на компьютере

Из существующей рабочей копии репозитория:

```powershell
git pull --ff-only origin main
& .\scripts\sync-marketplace.ps1
```

Скрипт подключает Git-источник в Codex вместо старой копии в Obsidian, обновляет каталоги и установленные плагины обеих программ. Сохраняет включённые и отключённые плагины; новые плагины сам не включает. Для первоначальной установки шести используемых плагинов на другом компьютере добавьте `-InstallDefaults`. Курс `vibe-coding-course` остаётся доступным для отдельной установки.

Если установлена только одна программа, используйте `-Client Claude` или `-Client Codex`. Путь к нестандартному Claude Code можно передать параметром `-ClaudeCommand`.

Запущенные чаты продолжают пользоваться загруженными инструкциями. После обновления откройте новые чаты. В Claude также есть штатное автообновление: `/plugin` → Marketplaces → anton-toolkit-marketplace → Enable auto-update. Git push публикует изменения; он сам по себе не перезагружает открытые приложения.

## Опубликовать изменение

```powershell
npm ci --ignore-scripts
npm test
npm run build
npm run check
```

После этого сохраните в одном коммите изменённые исходники и результат сборки и отправьте коммит в `main`. Для Claude увеличьте версию изменённого плагина в его `.claude-plugin/plugin.json`. GitHub Actions также запускает сборку после изменения исходников в `main` и при необходимости сохраняет обновлённые пакеты Codex отдельным коммитом. Если сборка не прошла, последняя успешная версия Codex остаётся доступной; состояние видно на вкладке Actions репозитория.

Старый каталог Obsidian `.codex-sync/marketplace` больше не является источником. Его установщик перенаправлен на Git-репозиторий; архив предыдущей копии нужен только для отката. Не переносите личные правила, память и учётные данные из Obsidian в этот репозиторий.
